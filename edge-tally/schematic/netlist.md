# Edge Tally connection list

J1 (Pico GPIO header): GP11/physical pin 15 -> R1 10 kΩ -> 3V3; GP11 -> J2.1. J2.2 -> GND. Pico USB supplies power. Pico GP25 drives onboard LED. Grounds are common. Contact closure pulls GP11 low. This conceptual netlist is not a KiCad schematic and has no ERC validation.
