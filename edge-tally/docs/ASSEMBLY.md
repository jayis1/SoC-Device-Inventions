# Assembly

1. Use a Raspberry Pi Pico with headers; connect GP11 and GND to a two-pin terminal block.
2. Install 10 kΩ from GP11 to 3V3 if you do not enable the internal pull-up.
3. Before connecting a contact, verify it is electrically unpowered and isolated from its original circuit.
4. Build and run the portable core test as described in the device README. The test does not flash or exercise Pico hardware.
