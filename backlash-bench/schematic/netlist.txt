Backlash Bench wiring contract (not a KiCad netlist):
Pico GP4 (I2C0 SDA) -> TCA9543A SDA and upstream pull-up to 3V3
Pico GP5 (I2C0 SCL) -> TCA9543A SCL and upstream pull-up to 3V3
TCA9543A channel 0 SDA/SCL -> input AS5600 SDA/SCL
TCA9543A channel 1 SDA/SCL -> output AS5600 SDA/SCL
TCA9543A address pins -> GND (7-bit address 0x70)
Pico 3V3_OUT -> TCA9543A VCC, sensor module VCC (only confirmed 3V3 modules)
Pico GND -> common sensor and switch ground
Pico GP6 -> SPST switch -> GND, internal pull-up enabled
Pico GP25 -> onboard status LED
Pico USB -> host and 5 V input
All I2C pull-ups must terminate at 3V3; avoid duplicate strong module pull-ups.
